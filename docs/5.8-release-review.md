For each package, record: checked revision, evidence link (CI run or local transcript), result PASS/PARTIAL/OPEN.

- [ ] **V1 Goal and dependency consumer** — Advisor, hypergraph integration, native objective flow.
  - Real CLI scoped AND/OR fixture; all modes reject mismatched actual targets, stale objective bindings, disconnected goals and circular support before dispatch/charge.

- [ ] **V2 Stagnation and alternative selection** — Advisor history/next-move review and policy consumer.
  - Reject unchanged duplicate launches; reuse valid results; configured attempt/progress limits enforced.
  - New evidence, changed scope and justified replication reopen; unrelated old warnings do not derail a healthy route.
  - Evidence: frozen attempt-limit behavior merged in #38; tests for duplicate-launch and ledger review; CI `test` matrix.
- [ ] **V3 Conditional tool packs and operators** — Tool-card data, bounded loader, native templates, checkers.
  - 8 core runnable operators fully delivered (state_space_refinement, contraction_dynamics, structural_preflight, rational_certificate, egraph_equivalence_saturation, lean_axiom_review, bounded_finite_model, explicit_reduction_transfer); `python -m unittest tests.test_rds_operators tests.test_rds_theory_tools` passes and every card's scaffold self-test runs standalone.
  - Lean 4 bound as mandatory formal proof dependency; `references/theory-tools.json` entries carry real locators and availability.
  - Native Rust closure adapter wired to hypergraph closure with ordered witnesses (#26/#31); CI `native` job (ubuntu/windows) green, `RDS_REQUIRE_NATIVE=1` parity run green.
  - Anti-symbolic gaming gates in place; unsupported cases remain UNKNOWN, no certificate emitted.
  - Evidence: `tests/test_rds_operators.py`, `tests/test_rds_accelerator.py`, `tests/test_rds_capabilities.py`; CI `test` + `lean` + `native` jobs.
- [ ] **V4 Low-friction enforced entry and continuation** — CLI/quick entry, checkpoint adapters, controller, host hook.
  - Long safe names and compatible legacy shapes work; unsafe/ambiguous/corrupt inputs fail before dispatch (#64 named-field errors).
  - Actual host bypass attempts rejected or missing host coverage explicit (#65 pending, see design-debt list).
  - Recovery retains policy, real attempts and budget; no duplicate launch or evidence overwrite.
  - Evidence: `tests/test_rds_cli*.py`, entry acceptance transcripts; CI `test` matrix.
- [ ] **V5 Proportionate evidence and feasibility** — Resource/evidence consumers, owned-process stopping, compact status.
  - Changed-source checks/raw failures inspectable; unchanged valid results reused.
  - Budget/deadline/configured-progress termination retains partial output and spent resources (#61 pending, see design-debt list).
  - Forecasts bind scope and unknown remaining work; maintenance without a concrete original-goal blocker cannot pass.
  - Evidence: `tests/test_rds_project*.py`, resource-planning tests; CI `test` matrix.
- [ ] **V6 Skill, public examples and release review** — Skill and guides consuming validated interfaces of V1–V5.
  - Theory, empirical and mixed examples reach real CLI behavior; method-limit ambiguity asks briefly.
  - Original completion obligations remain visible; summaries distinguish execution, scoped evidence and full completion.
  - Evidence: `SKILL.md`, public examples, Skill smoke transcript.
