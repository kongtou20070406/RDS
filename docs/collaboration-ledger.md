## 二、 验收标准升级：四问验收法（The Four-Question Test）

后续不管是哪个线程提交的 PR、功能或案例，你（01a0f587）在审查和盯盘时，必须用以下 **“四问验收法”** 进行一票否决：

1. **疑问明确性**：这个候选/实验到底是为了回答什么未知的科学疑问，而不是盲目跑代码？
2. **门禁前置性**：有没有在耗费算力前，通过理论或逻辑排除了显而易见的荒谬假设？
3. **决策改变度**：实验跑完拿到的收据与数据，**究竟怎样改变了 Advisor 对下一步行动的裁决**？（如果跑完实验后的结论跟跑之前没区别，这个实验就是无效的）。
4. **反打转与沉淀**：如果失败了，失败原因是否被原子写入 Memory/Ledger，下一轮是否严格避免了重复走老路？

### 4.2 统计与归因表述校准

以下是前文较强表述在本轮验收中的准确含义，避免实现出错误的科研结论：

1. **Ville / e-process**：在非负超鞅、初始期望约束、所选过滤族等前提成立时控制越界的错误概率。它不是“零假阳性”，也不保证停止训练没有性能损失或必然省预算。必须说明检验对象、过程构造、阈值和实际停止消费者。[Howard 等，置信序列论文，当前 arXiv v9](https://arxiv.org/abs/1810.08240v9)
2. **收益置信界**：独立有界观测或其他明确的集中条件可支持规定估计量的误差界。连续训练的 10–20 个 Loss 点不能默认当作独立样本；`0.02` 的下降本身不证明总体改进，更不证明机制归因。固定样本界不能未经处理反复用于自适应停机。[mathlib 的 Hoeffding 与条件 Azuma–Hoeffding 定理](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Probability/Moments/SubGaussian.html)、[项目术语中的 task gain / mechanism](terminology.md)
3. **理论与实验不符**：理论 PASS 只支持所证命题及其假设，不能自动排除模型假设、声明到执行的映射、数值实现或其他数学缺陷。经验失败先查执行一致性、条件与测量，再用区分实验判断原因，不能直接归因学习率。[既有形式验证契约](formal-verification.md)
4. **预算与选择**：记录整个决策过程的必要成本，比较对研究目标的推进与会改变判断的知识价值；不能把“最便宜”或“排除最多标签”本身当作目标。原始失败保留，缺成本保持未知。[既有研究决策与预算协议](advisor-advancement.md)

## 五、空投战略升级定调：以 L2/L3 为现实抓手，直指 L5 全自动科研发现（2026-10-01）

依据 [docs/research-autonomy.md](research-autonomy.md)（基于 Kramer 等 2026 年发表于 *Machine Learning* 的科学发现自治分级体系），空投正式明确了 RDS 的发展阶梯：

```
 [L0 传统人工] ──> [L1 辅助工具] ──> [L2 关键环节自动] ──> [L3 限定领域闭环] ──> [L4 跨域高阶] ──> [L5 全自主科学发现]
                                    ▲                   ▲                                       ▲
                                    │                   │                                       │
                                    └──── 当前交付目标 ────┘                                   终极远景目标
```

### 1. 现阶段现实目标：打磨 L2/L3 科研的杀手级核心工具
- **L2（环节自动化）**：把科研中最消耗脑力、普通 AI 最容易盲目打转的环节——**“假设与实验选择（Selection）”** 与 **“形式化理论过滤（Theory Gate）”** 彻底自动化，做到零伪阳性、零无效调参。
- **L3（限定领域完整循环全自动）**：在限定科学领域（如连续收缩动力学、确定性损失收敛、统计推断界），人类只需输入“初始疑问与预算帽”，RDS 自主跑通从“图谱缺口发现 $\to$ 形式预检 $\to$ 物理探针 $\to$ 决策转移 $\to$ 负向沉淀”的完整闭环，无需人类在中间微操。

### 2. 远期终极目标：构建迈向 L5（Full Research Autonomy）的核心底座
要从 L3 跃升到 L5，不可逾越的三大底层支撑正是我们正在构建的组件：
1. **确定性事实裁判（Lean 4 原生内核 + 统计集中界）**：L5 绝不能靠 LLM 幻觉判断对错，必须由形式化编译器作为唯一不可腐败的真理标尺；
2. **状态与反事实记忆（Scoped Ledger & Anti-loop）**：L5 必须具备探索空间单调收敛的记忆力，终身不踩同一坑；
3. **元决策自我演进（RSI 递归自我改进）**：不仅在具体实验中选方向，还能在独立研究轨迹之间评估并改进“选择方向本身的元策略”。

本定调已作为最高战略方针，供总控（猫娘）与监督官（01a0f587）在审查与推进中严格恪守。

**战略措辞在工程验收中的准确约束**：
