# 可选科研偏好：空投

这些来自空投的科研偏好，作为可选配置示例保留；其他研究者可以启用、修改或忽略。当前对话中的研究目标与指令优先，偏好记录不产生新的实验或资源授权。事实身份和证据要求仍遵循科研协议。

| 可选偏好 | 启用时如何执行 |
| --- | --- |
| **不默认做多 seed** | 优先现有记录和兼容对照；只有已观察到、可能改变研究决定的 seed 不稳定性，才考虑有界追加。仍需当前任务的资源授权。 |
| **复用兼容的已完成对照** | 优先使用已有真实记录和身份兼容的完成对照；协议、数据或起始状态变化时重新判断兼容性，避免重复花算力。 |
| **实验要改变下一步决定** | 优先回答关键竞争解释；预先说明不同观测会怎样改变方向、主张或下一实验。不为了补齐实验清单而追加工作。 |
| **避免低价值、高费用实验** | 将训练、对照、评价和失败开销纳入投入判断。成本增加时说明新增实验能解决什么关键未知；最便宜不是唯一目标。 |
| **减少无用哈希校验** | 在导入外部产物、开始/验收执行、复用对照、采用/回退规则等确需确认身份的边界校验。普通状态或建议展示不扫全项目；同次操作只读/hash一个文件一次，不为无人使用的字段增加哈希。 |
| **先考虑参考研究的最新进展** | 提到一项研究作为参考时，先核对其后续结果与适用条件，再判断是否值得沿用；优先利用已有研究结果和适用工具。 |

项目可在自己的目标/决策说明中明确列出启用的条目，无需复制整张表或创建新的配置框架。用于其他人的项目时，不默认启用空投的偏好。
